Automation & AI

AI-Assisted Newsroom

A daily pipeline that turns the club's YouTube uploads and match results into polished news drafts, so volunteers don't have to write every update by hand.

Key details
  • Vercel Cron job secured with a bearer secret runs the sync every day
  • Claude API rewrites posts into articles under strict "never invent scores, quotes, or dates" rules
  • Relevance filter skips memes and off-topic posts automatically
  • Deduplication log so nothing is processed twice
  • Everything lands as a draft: a human reviews before anything is published
  • Uses YouTube's uploads playlist instead of search to save API quota
  • Claude API
  • YouTube Data API
  • Vercel Cron
  • Supabase
